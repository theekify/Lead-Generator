# Automated Lead Generation Scraper

A Python-based automated lead generation tool that extracts structured entity data from multi-page listings and individual profile pages.  
The project demonstrates real-world web scraping, pagination handling, and data extraction workflows used in lead generation systems.

---

## 🚀 Features

- Scrapes entities from multi-page listing pages
- Visits individual profile pages for deeper data extraction
- Extracts structured lead information:
  - Lead name
  - Unique identifier (SKU / ID)
  - Metadata (price or attributes)
  - Profile URL
- Handles pagination automatically
- Exports clean, structured data to CSV format

---

## 🧰 Tech Stack

- **Python 3**
- **Requests** – HTTP requests
- **BeautifulSoup4** – HTML parsing
- **Pandas** – Data structuring & CSV export

---

## ⚠️ Disclaimer
This project is intended for educational and demonstration purposes only.
All data scraped is publicly available, and no authentication or protected content is accessed.
